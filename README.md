# 망고키즈수영장 홈페이지

어린이 수영과 생존수영 교육을 소개하는 반응형 정적 홈페이지 프로젝트입니다.

## 파일 구성

- `index.html`: 홈페이지 전체 페이지와 반응형 스타일
- 배포 방식: GitHub Pages 또는 정적 웹 호스팅

## 로컬에서 보기

`index.html`을 브라우저에서 열면 확인할 수 있습니다. 별도 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 수정할 때

프로그램 안내, 지점 정보, 전화번호를 변경할 때는 `index.html`의 해당 문구와 링크를 함께 수정하세요. 현재 초안에는 알려진 지점 및 상담 정보를 바탕으로 콘텐츠를 넣었습니다.

## 참고

현재 저장소는 비공개입니다. 공개 배포 전에는 지점별 주소·전화번호와 수업 안내를 확인해 주세요.
