홈페이지 관리자

홈페이지 문구와 수업 안내를 수정하고, 변경 내용을 실제 사이트에 반영할 수 있어요.

GitHub 로그인 후 관리자 열기
  1. 1. GitHub 계정으로 로그인
    사이트 저장소에 접근 권한이 있는 계정으로 로그인해 주세요.
  2. 2. 저장소 선택
    keichirotaku/mango-kids-swimming-school을 선택한 뒤 “홈페이지 콘텐츠”를 엽니다.
  3. 3. 수정하고 저장
    메인 문구, 수업 안내, 등록 혜택, FAQ, 지점 정보를 수정하고 저장합니다.
저장하면 변경 내용이 GitHub 저장소에 기록되고, GitHub Pages 배포가 완료된 뒤 홈페이지에 반영됩니다. 비밀번호는 이 사이트에 저장되지 않습니다. 관리자 도구에 GitHub 접근 권한을 연결해야 처음 사용할 수 있습니다.
